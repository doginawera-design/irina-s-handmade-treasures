# Цифровое ателье Ирины Гасниковой

Сайт-витрина авторских текстильных кукол и игрушек ручной работы. Эстетика «цифрового льна» — тактильный, тёплый, журнальный дизайн вместо стандартного интернет-магазина.

---

## Дизайн-система

- **Палитра:** тёплый молочный фон, мягкая охра как основной акцент, пыльная роза для кнопок и плашек, глубокий антрацит для текста (без чистого чёрного)
- **Типографика:** Fraunces (серифный, для заголовков) + Instrument Sans (для UI и текста)
- **Карточки:** без жёстких бордеров — только мягкие тени, имитирующие объём ткани. Радиус: кнопки 8px, карточки 24px
- **Анимации:** плавное проявление при скролле, мягкое увеличение фото при наведении (scale 1.02), пружинистое нажатие кнопок (scale 0.98)

---

## Структура страниц

### 1. Header

- Прозрачный фон с backdrop-blur
- Логотип «Ирина Гасникова» (Fraunces)
- Меню: Мастерская · Коллекции · Доставка · Контакты
- Иконка корзины с числовым индикатором

### 2. Главная страница (Hero)

- Асимметричная композиция: крупное фото куклы справа, заголовок «Игрушки с душой и историей» слева
- Кнопка «Смотреть коллекцию» (outline, заполнение при ховере)
- Блок «Мастерская» — рассказ о процессе создания + форма заявки на индивидуальный заказ
- Секция избранных работ

### 3. Каталог (Коллекции)

- Masonry-подобная сетка (2–3 колонки, разная высота)
- Текстовые фильтры: Все / Куклы / Зверята / В наличии
- Карточка товара: фото с мягким zoom при наведении, название, цена, статус «В единственном экземпляре»

### 4. Страница товара (История изделия)

- Слева: вертикальный скролл крупных фото (детали: швы, пуговицы, фактура)
- Справа (sticky): название, «биография» куклы, материалы (лен, хлопок, опилки), кнопка «Забрать домой»
- Язык приглашения вместо агрессивных продаж

### 5. Корзина (Drawer)

- Выезжает справа по клику на иконку
- Заголовок «Ваш выбор»
- Список выбранных изделий, итоговая сумма, кнопка «Оформить заказ»

### 6. Оформление заказа

- Минимум полей: имя, телефон, email, способ доставки, адрес
- Деликатное подтверждение заказа (toast-уведомление)

### 7. Страница «Доставка»

- Информация о способах и сроках доставки, стоимость
- Чистая типографика, ширина строки 65ch

### 8. Политика конфиденциальности

- Юридический текст, чистая типографика

### 9. Оферта

- Публичная оферта, чистая типографика

### 10. Footer

- 4 колонки: Навигация, Соцсети (VK), Юридическое (Оферта, Политика), Подписка на анонсы
- «Сделано с любовью в мастерской Ирины Гасниковой»

## Админ-панель (The Workbench)

Отдельный раздел `/admin` со стилем Linear — чистый и функциональный.

- **Вход:** простая авторизация по email/паролю
- **Заказы:** список заявок в виде карточек (данные клиента, товар, статус: Новый / Оплачен / Отправлен). Смена статуса в один клик
- **Товары:** добавление и редактирование (название, описание, цена, категория, статус «В наличии / Под заказ», загрузка фото)
- **Настройки:** редактирование стоимости доставки

---

## Бэкенд (Supabase)

- **Auth:** авторизация для админа
- **Database:** таблицы products, orders, order_items, settings, user_roles
- **Storage:** хранение фото товаров
- **RLS:** политики доступа — публичное чтение товаров, запись только для админа

---

## Данные (без бэкенда на первом этапе)

На старте все данные будут демонстрационными (mock-данные), структура готова к подключению Supabase. Товары, заказы и корзина работают через React state/context.
